Website institucional responsivo desenvolvido para a **Alternativa**, um espaço cultural independente localizado no Rio de Janeiro que integra gastronomia, drinks autorais, tecido acrobático e artes visuais.

Este projeto funciona como um excelente exemplo de **landing page corporativa moderna**, focada em altíssima fidelidade de design (UI/UX), animações fluidas no scroll e otimização para mecanismos de busca (SEO).

---

## 🎯 Melhores Práticas & Destaques Técnicos

Para ir além de uma página estática simples, o projeto foi desenvolvido seguindo padrões profissionais de front-end de mercado:

- **Estruturação Semântica HTML5:** Utilização rigorosa de elementos semânticos (`<header>`, `<nav>`, `<section>`, `<footer>`) para garantir melhor indexação em motores de busca e acessibilidade de leitores de tela.
- **Arquitetura CSS Moderna:** Uso de CSS Custom Properties (Variáveis de ambiente) para centralizar a paleta de cores (Design Tokens), facilitação de manutenção e consistência visual. Layout responsivo robusto construído exclusivamente com **CSS Grid** e **Flexbox** (sem bibliotecas externas).
- **Interatividade Nativa (Vanilla JS):** Menu mobile retrátil com controle de estado de acessibilidade (`aria-label`) e efeitos de animação fade-in-up acionados dinamicamente via JavaScript conforme o usuário rola a página (Intersection Observer simplificado).
- **Otimização para SEO & Open Graph:** Configuração completa de metatags de descrição e protocolo Open Graph para geração dinâmica de pré-visualizações ricas ao compartilhar o link em redes sociais (WhatsApp, LinkedIn, Instagram).
- **Visual Premium (Aesthetics):** Efeito de desfoque de vidro (*glassmorphism*) na barra de navegação, overlays de gradiente com hover dinâmico na galeria de fotos e mapa em escala de cinza invertida integrado.

---

## 🚀 Funcionalidades da Interface

- **Hero Banner Interativo:** Introdução dinâmica com gradiente de luz radial e chamada para ação (CTA) integrada à rede social oficial do estabelecimento.
- **Seção de Eventos com Destaque:** Cartões informativos de agenda com badges dinâmicos de preço e destaque de evento principal.
- **Cardápio Visual e Dinâmico:** Seção organizada de cardápio com preços, descrições detalhadas e categorias estruturadas.
- **Galeria de Fotos Responsiva:** Grid interativo exibindo imagens do local físico, apresentações de circo aéreo e produtos, com efeitos de ampliação (*zoom on hover*).
- **Localização com Mapa Personalizado:** Mapa interativo integrado que se ajusta automaticamente ao tom dark-mode do design através de filtros de CSS.

---

## 🛠️ Tecnologias Utilizadas

- **Estrutura:** HTML5 Semântico
- **Estilo:** CSS3 (Custom Variables, Flexbox, Grid, CSS Filters)
- **Comportamento:** Vanilla JavaScript (ES6+)
- **Mapas:** Google Maps Embed API
- **Imagens:** Imagens de alta fidelidade geradas por inteligência artificial

## 🔧 Como Executar Localmente

Como o projeto é construído em front-end estático nativo (sem a necessidade de compiladores ou bundlers), a execução é extremamente simples:

1. **Clonar o Repositório:**
   ```bash
   git clone git@github.com:robertofmarins/python-tkinter-postgres-crud.git # Substitua se necessário
   ```
2. **Abrir a Página:**
   - **Opção A (Simples):** Basta dar dois cliques no arquivo `index.html` para abrir diretamente em qualquer navegador moderno.
   - **Opção B (Recomendada para Desenvolvimento):** Abra a pasta do projeto no VS Code, instale a extensão **Live Server** e clique em **Go Live** no canto inferior direito.
